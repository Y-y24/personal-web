# 个人学术主页设计文档

> 日期：2026-06-02
> 状态：已确认

## 概述

为信息工程专业学生打造的个人学术主页，部署在 GitHub Pages，面向意向研究生导师展示个人能力与经历。中英双语，简洁专业。

## 技术栈

| 层 | 选择 | 说明 |
|----|------|------|
| 构建 | Vite | 开发热更新，打包优化，多页入口 |
| HTML | 原生 HTML | 无框架依赖 |
| CSS | 原生 CSS + CSS Variables | 主题色统一管理，响应式 |
| JS | 原生 JS | DOM 渲染、语言切换 |
| 部署 | GitHub Pages | GitHub Actions 自动部署 `gh-pages` 分支 |
| 图标 | 内联 SVG | 零外部依赖 |

## 页面结构

单页滚动布局，顶栏固定导航，锚点跳转至各区域：

1. **首屏 / Hero** — 头像、姓名、信息工程专业、一句话简介、简历下载 + 联系按钮
2. **关于 / About** — 2-3 段自述（学术兴趣、研究经历概况、未来规划）
3. **项目 / Projects** — 项目卡片网格（标题、描述、技术栈标签、截图、GitHub 链接）
4. **研究 / Research** — 论文标题、发表情况、摘要、链接
5. **获奖 / Awards** — 时间线列表（时间、竞赛名称、获奖等级、说明）
6. **技能 / Skills** — 按类别分组（编程语言、硬件、工具），标签形式展示
7. **经历 / Experience** — 时间线（教育背景、实习/实验室经历）
8. **联系 / Contact** — Email、GitHub、其他链接

导航栏右上角 **中/英切换按钮**，点击切换所有文本。

## 视觉设计

### 配色

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | `#ffffff` | 主背景 |
| 浅色区块 | `#f8f9fa` | 交替区分各区域 |
| 主文字 | `#212529` | 深灰黑，保证可读性 |
| 强调色 | `#2563eb` | 链接、标签、进度条 |
| 标签背景 | `#e9ecef` | 技能/技术栈标签 |

### 字体

- 中文：系统默认（苹方 / 微软雅黑）
- 英文：Inter / 系统 Sans-serif
- 代码/标签：JetBrains Mono（从 Google Fonts 加载）

### 布局

- 最大内容宽度 `960px`，居中，留白充足
- 卡片式项目展示，2 列网格（移动端 1 列）
- 时间线用左侧竖线 + 圆点标记
- 首屏左右布局：左头像右信息

## 双语实现

- 所有文本存储在 `data/` 目录 JSON 文件中
- 页面加载时根据当前语言选择文本，JS 渲染 DOM
- 切换语言时重新渲染，无页面刷新
- 语言选择持久化到 `localStorage`

## 部署流程

1. `npm run build` → 生成 `dist/`
2. GitHub Actions 推送 `dist/` 到 `gh-pages` 分支
3. `main` 分支 push 触发自动部署
